## 执行步骤

### 步骤 1：批量转录（ffmpeg + FunASR）

**脚本**：`transcribe.py`

```bash
cd "C:/Users/hfhfn/Desktop/其他/mksz955-MCP+A2A 从0到1构建类Manus多Agent全栈应用资源"
conda activate llm_gpu
python transcribe.py 2>&1 | tee .transcribe_output.log
```

**流程**：
1. 遍历 `videos/` 下 20 个 `第N章` 目录，收集所有 `.mp4`
2. 对每个视频：
   - ffmpeg 提取音频为 16kHz 单声道 WAV → `.notes_intermediates/<章节>/<课时>.wav`
   - FunASR SenseVoiceSmall 转录 WAV → `.notes_intermediates/<章节>/<课时>.txt`
   - 删除 WAV 释放空间
3. 已存在的 `.txt` 自动跳过（断点续传）
4. 失败的记录到 `.transcribe_failed.log`

**预计耗时**：1-3 小时（SenseVoiceSmall 在 RTX 5060 上可达 20-25 倍实时速度）

**监控进度**：
```bash
# 查看实时输出
tail -f .transcribe_output.log
# 查看进度日志
cat .transcribe_progress.log
# 查看失败清单
cat .transcribe_failed.log
```

### 步骤 2：转录质量抽检

随机抽查 3-5 个 `.txt` 文件，确认中文识别质量：
```bash
cat ".notes_intermediates/第11章 Playwright.../11-15 本章总结+.txt"
```

重点关注：
- 技术术语是否正确（MCP、A2A、FastAPI、Redis、Playwright 等）
- 是否有大量乱码或遗漏

### 步骤 3：Claude 撰写 Markdown 笔记

转录 txt 就绪后，由 Claude 撰写笔记。

**笔记模板**（每个 `.md` 包含）：
1. **标题**：课时标题
2. **内容摘要**：3-5 句概括本节内容
3. **正文**：
   - 按知识点分层级标题（# → ## → ###）
   - 代码/命令用代码块，标注语言
   - 操作步骤用有序列表
   - 关键概念用 **粗体** 或 `行内代码`
4. **核心要点**：结尾总结

**修正规则**：
- 修正明显的语音识别错别字（结合课时标题和上下文）
- 技术术语按实际含义修正（如 "play外" → "Playwright"、"brother" → "Browser-Use"、"CTP" → "CDP"）
- 不编造原文没有的内容

**执行策略**：
1. 先处理 1-2 个课时（如 `1-1`、`2-1`）确立质量标准
2. 按章节并行处理（可用 Agent 子代理分工）
3. 每章笔记写完即保存至 `notes/<章节>/<课时>.md`

### 步骤 4：生成总索引

完成后生成 `notes/index.md`：
```markdown
# 课程笔记总索引

## 第1章 课程介绍与安排
- [1-1 快速了解课程和安排](videos/第1章 课程介绍与安排/1-1 快速了解课程和安排.md)

## 第2章 Agent应用开发全景
- [2-1 本章介绍](第2章 Agent应用开发全景.../2-1 本章介绍.md)
- ...
```

### 步骤 5：完整性验证

核对 248 个视频是否都有对应 `.md`：
```bash
# 统计 notes 目录下的 .md 数量
find notes -name "*.md" | wc -l
# 对比视频数量
find videos -name "*.mp4" | wc -l
```

列出缺失项逐一补写。

## 常见问题

### 1. FunASR 模型未下载
首次运行会自动下载 ~1GB 模型文件。如果卡住或中断：
```bash
# 手动从 modelscope 下载
python -c "
from modelscope import snapshot_download
snapshot_download('iic/SenseVoiceSmall', cache_dir='./model_cache')
"
```

### 2. 转录失败
- 检查 GPU 是否被使用：`nvidia-smi`
- 检查音频是否正常提取：`ls -la .notes_intermediates/*/`
- 查看失败日志：`cat .transcribe_failed.log`
- 单独重试：修改 transcribe.py 只处理单个文件

### 3. 中文识别质量差
- 确保 `language="zh"` 参数正确
- 确保使用 `use_itn=True`（逆文本正则化）
- 确保使用 `merge_vad=True`（合并 VAD 片段）

### 4. 转录完成后清理中间文件
```bash
# 删除所有 .wav 文件（txt 已就绪）
find .notes_intermediates -name "*.wav" -delete
# 可选：删除整个 intermediates 目录
rm -rf .notes_intermediates
```

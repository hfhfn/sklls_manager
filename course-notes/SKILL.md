# course-notes — 转录 → 结构化笔记（+ 索引）

把 `.notes_intermediates/第N章/…txt` 写成 `notes/第N章/X-Y 标题.md`，并维护 `topics.json` / `总索引.md`。

## 笔记模板（每篇 .md）
1. **标题**：课时标题。
2. **内容摘要**：3–5 句概括。
3. **正文**：按知识点分层级标题（`#`→`##`→`###`）；代码/命令用带语言标注的代码块；操作步骤用有序列表；关键概念用**粗体**或 `行内代码`。
4. **核心要点**：结尾总结。

## 修正规则
- 结合**课时标题 + 上下文**修正明显 ASR 错别字。常见误听归一化：
  `play外`→`Playwright`、`brother`→`Browser-Use`、`CTP`→`CDP`、`story`→`store`，以及 MCP / A2A / FastAPI / Redis 等术语。
- **绝不臆造**转录里没有的内容。代码块可据上下文补全到自洽，但业务逻辑须忠于讲解。

## 命名（干净约定）
- `&amp;`→`&`（或"和"）、去掉 `【公众号：…】` 等后缀、整理标题。
- 因此笔记名与转录名**不 1:1**，按"课时号 + 主题"对应（见 `course-pipeline` 的命名坑）。
- 每章每课时保持 1:1（一课时恰好一篇笔记）。

## 索引维护
新增/删除/改名笔记后：
1. 在 `notes/topics.json` 写该课时主题：`"X-Y": "凝练主题"`（2–4 个关键点，顿号/斜杠分隔，~8–26 字，无句号结尾）。
2. 跑生成器重建索引（脚本 `scripts/gen_index.py` **随技能自带**；本仓库根目录另有一份便于直接 `python gen_index.py`）：
```bash
# 本项目根目录直接跑：
python gen_index.py
# 或跑技能自带副本（复用到新课程时先改脚本顶部 ROOT）：
python skills/course-notes/scripts/gen_index.py
```
`gen_index.py`：优先用 `topics.json` 的主题；无则回退抽取该篇 `## 内容摘要` 首句；链接对空格与括号做百分号编码（`)` 会提前截断 Markdown 链接）。脚本顶部 `ROOT` 为绝对路径常量，**换课程须先改这一行**（自带副本已在该行上方加提示）。

## 批处理
按章分派并行子代理撰写；每章写完即校验 1:1 对齐，再合并写 `topics.json` + 跑 `gen_index.py`。
